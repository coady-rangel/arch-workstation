# Release v4.2.0 — Toolkit Release Management

## Overview

This release adds a complete Release Management workflow to the Arch Workstation Toolkit.

The new tooling provides a guided interface for inspecting release state, validating releases, publishing new releases, viewing GitHub releases, and backfilling missing GitHub releases from existing Git tags.

---

## Added

- Release Management menu under Engineering
- Release Status view
- Release validation workflow
- Publish Release workflow
- GitHub release listing
- Backfill Missing Releases workflow
- Semantic version validation
- Local and remote tag collision checks
- GitHub authentication checks
- Release notes validation
- Publish confirmation guardrails
- Consistent publish, validation, and backfill summaries

---

## Improved

- Release validation now handles non-zero exit codes safely under `set -e`
- Release commands run from the repository root when required
- Working tree status reporting is more reliable
- Release operations now fail safely instead of unexpectedly terminating the Toolkit

---

## Release Workflow

The Toolkit can now guide the full release lifecycle:

1. Inspect repository and release status
2. Validate release readiness
3. Publish a new Git tag and GitHub Release
4. Review published GitHub releases
5. Backfill missing releases for existing tags

---

## Validation

Release Management was tested for:

- Existing tag rejection
- Invalid version rejection
- Missing release notes
- Dirty working tree validation
- Release cancellation
- GitHub authentication checks
- No-op backfill when all tags already have releases
- Toolkit return-to-menu behavior after failed validation
